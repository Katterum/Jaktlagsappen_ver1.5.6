# Jaktlaget 1.5.6 Stable

Bygger direkt vidare på 1.5.5.1 med avgränsade ändringar.

- Färgkodning av erhållet vilt mot markandel på statistiksidan.
- Statusfilter och sökning i vilthistoriken.
- Historikkort visar mottagare, procentandel och vuxenekvivalent.
- Varningskort på hemsidan för ofärdiga fördelningar.
- Varning vid jaktårsbyte om ofärdiga fördelningar finns.
- Befintliga funktioner och övrig layout har lämnats oförändrade så långt möjligt.
